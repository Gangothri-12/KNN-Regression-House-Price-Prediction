# KNN Regression – House Price Prediction

## Project Overview
This project uses the K-Nearest Neighbors (KNN) Regression algorithm to predict house prices using the California Housing Dataset.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Dataset Loading
2. Data Exploration
3. Data Preprocessing
4. Train-Test Split
5. Feature Scaling using StandardScaler
6. KNN Regression Model Training
7. House Price Prediction
8. Model Evaluation
9. Distance Metrics Comparison

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Algorithm
K-Nearest Neighbors (KNN) Regression

## Conclusion
This project demonstrates how KNN Regression can be used to predict house prices and evaluate model performance using different regression metrics.
